Dapur Panas: Kitchen Rush — a fast top-down cooking game in the spirit of Overcooked 2. Run a busy kitchen alone: grab ingredients from the crates, chop them on the boards, fry patties, simmer soup, wash the dirty plates, and serve every order before its timer runs out. Five recipes, a 3-minute shift, combos for back-to-back perfect serves, and difficulty that ramps up as the rush builds.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, interact with E or Space (hold E to chop and wash), dash with Q, or click a station to walk over and use it. Press R to restart a shift.
